# Odoo Purchase Module - Functional Manual Testing Portfolio

## 📌 Project Overview
This repository contains end-to-end *Functional Manual Testing* artifacts for the *Odoo Purchase Management Module*. The objective of this project is to validate critical procurement workflows, including vendor management, Request for Quotations (RFQs), Purchase Orders (POs), vendor bills, and receipt validations.

---

## 🎯 Testing Scope

### Modules & Features Tested:
* *Vendor Management:* Creating and updating vendor details and pricelists.
* *RFQ Creation & Management:* Drafting, editing, and sending Request for Quotations via email.
* *Purchase Order (PO):* Converting RFQs into Purchase Orders and tracking status.
* *Goods Receipt (Grn/Receipts):* Validating partial and full item reception.
* *3-Way Matching & Invoicing:* Verifying Vendor Bills against Purchase Orders and Received Quantities.
